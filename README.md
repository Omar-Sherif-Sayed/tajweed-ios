# Tajweed — iPhone application · تجويد — تطبيق آيفون

Part of **Tajweed - The Noble Quran and Its Sciences** (تجويد - القرآن الكريم وعلومه): a free Islamic application for the
Quran, its recitation and its sciences — web, Android and iPhone, Arabic and English. No advertisements, no
registration, no login, no tracking.

> **State (2026-11-17): empty.** No code yet — this repository was created so that the work has a home. The project
> is scaffolded in task `P0-10` of the plan.

## What this repository will hold

The iPhone application. Bundle id: `io.github.omarsherifsayed.tajweed`.

Planned technology: Swift · SwiftUI · AVFoundation.
